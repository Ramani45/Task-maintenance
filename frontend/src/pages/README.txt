-----------------------------------------------------------
1. PROJECT OVERVIEW
-----------------------------------------------------------
This project is a high-performance Full-Stack Application designed to manage 
operational tasks for a Shopping Mall Management System. It enables team 
collaboration, task tracking, and professional progress monitoring through 
a modern web interface.

-----------------------------------------------------------
2. TECHNICAL STACK
-----------------------------------------------------------
- Frontend: React / Angular (Responsive Web Design)
- Backend: Java Spring Boot (RESTful API Architecture)
- Database: PostgreSQL / MongoDB (BSON Data Handling)
- Deployment: Railway / GitHub Actions
- Professional Tools: LaTeX (Resume Integration), Git

-----------------------------------------------------------
3. KEY FEATURES
-----------------------------------------------------------
- Career Readiness Hub: Real-time skill matrix and portfolio tracking.
- Interactive Task Board: Kanban-style management for mall operations.
- Backend Integration: Spring Data JPA for persistent storage and 
  PostgreSQL management.
- Live Monitoring: Frontend system log and performance analytics.

-----------------------------------------------------------
4. INSTALLATION & SETUP
-----------------------------------------------------------
A. Backend (Spring Boot):
   1. Navigate to the backend folder.
   2. Configure your application.properties with your database credentials.
   3. Run 'mvn spring-boot:run'.

B. Frontend (React/Angular):
   1. Navigate to the frontend folder.
   2. Run 'npm install' to fetch dependencies.
   3. Run 'npm start' to launch the local development server at localhost:3000.
